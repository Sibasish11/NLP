# Week 1 — Summary

**One-line takeaway:** NLP is hard because human language is ambiguous at every level, from individual words to full context.

## Must-know concepts
- NLP sits at the intersection of linguistics, computer science, and machine learning.
- Ambiguity types: lexical, syntactic, semantic, pragmatic, referential.
- Six levels of linguistic analysis: phonetics/phonology, morphology, syntax, semantics, discourse, pragmatics.
- NLP evolution: rule-based → statistical → machine learning → deep learning.
- Core applications: MT, IR, sentiment analysis, chatbots, summarization, NER, speech recognition, QA.

## Key formulas
- None this week — conceptual foundation only.

## Common pitfalls / gotchas
- Don't confuse syntactic ambiguity (structure) with semantic ambiguity (meaning) — "I saw the man with the telescope" is syntactic; "visiting relatives can be boring" is semantic.
- Pragmatics is often overlooked but critical — "Can you pass the salt?" is a request, not a literal yes/no question.

## If you only remember one thing
> Every NLP problem is ultimately a problem of resolving ambiguity using context.
